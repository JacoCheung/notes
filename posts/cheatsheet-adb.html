安装与设备选择

06
macOS 安装
brew install --cask android-platform-tools

需先安装 Homebrew

Termux 安装
pkg install android-tools

安装 ADB 客户端；不等于已取得手机调试授权

版本与帮助
adb version
adb help
列出连接设备
adb devices -l

USB 需开启调试；unauthorized 时解锁手机确认授权

指定设备
adb -s SERIAL shell

用 devices 返回的序列号替换 SERIAL；-s 位于子命令前

按连接类型选择
adb -d get-state
adb -e get-state

-d USB；-e TCP/IP；同类型有多台时改用 -s

无线连接

06
无线配对
adb pair 192.168.1.20:37001

Android 11+ 手机；使用配对弹窗端口，按提示输入配对码

连接无线设备
adb connect 192.168.1.20:38001

使用无线调试主页的连接端口，与配对端口不同

发现无线调试服务
adb mdns check
adb mdns services

通常要求同一网络；服务可见性取决于 mDNS

断开指定无线设备
adb disconnect 192.168.1.20:38001

不带地址会断开所有 TCP/IP 设备

传统 TCP 调试
adb tcpip 5555
adb connect 192.168.1.20:5555

通常先经 USB 授权；仅可信网络，不是 TLS 无线配对模式

恢复 USB 监听
adb usb

重启目标 adbd 的监听；传统 TCP 调试完成后使用

文件与存储

07
上传文件
adb push ./note.txt /sdcard/Download/

本机 → 设备；目录也可传输

下载文件
adb pull /sdcard/Download/note.txt ./note.txt

设备 → 本机；-a 保留时间与权限模式

增量上传
adb push --sync ./assets /sdcard/Download/

按修改时间跳过未更新文件；不清理远端多余文件

列目录
adb shell ls -lah /sdcard/Download

文件访问仍受设备权限限制

创建目录
adb shell mkdir -p /sdcard/Download/adb-demo
存储占用
adb shell df -h /sdcard
adb shell du -sh /sdcard/Download
删除指定文件
adb shell rm /sdcard/Download/adb-demo/note.txt

直接删除；执行前确认设备路径

应用安装

07
安装 APK
adb install ./app.apk

-t 允许测试 APK；-g 授予运行时权限

覆盖安装
adb install -r ./app.apk

保留应用数据；签名须兼容，不能任意降级

安装 split APK
adb install-multiple base.apk split_config.arm64_v8a.apk

同一应用；需包含与设备匹配的全部必需 splits

卸载应用
adb uninstall com.example.app

默认删除数据；-k 保留数据与缓存

清空应用数据
adb shell pm clear com.example.app

保留 APK；删除应用数据与登录状态

列出已安装应用
adb shell pm list packages -3

-3 第三方；-s 系统应用；-f 显示 APK 路径

查询 APK 路径
adb shell pm path com.example.app

split 安装会返回多个路径；下载需逐个 pull

应用运行

06
进入设备 Shell
adb shell

exit 退出；设备上的 shell 用户，不等于 root

启动 Activity
adb shell am start -W -n com.example.app/.MainActivity

-W 等待启动结果；替换为实际组件名

打开 URL
adb shell am start -a android.intent.action.VIEW -d https://example.com/

由设备上的匹配应用处理

停止指定应用
adb shell am force-stop com.example.app

停止该包相关进程，不卸载、不清数据

发送应用广播
adb shell am broadcast -a com.example.app.PING -p com.example.app

受组件导出与广播权限限制

运行 instrumentation 测试
adb shell am instrument -w com.example.app.test/androidx.test.runner.AndroidJUnitRunner

需已安装测试 APK；替换测试包与 runner

Logcat 日志

06
实时日志
adb logcat -v threadtime

Ctrl+C 停止；包含时间、PID 与 TID

按 tag 与级别筛选
adb logcat MyApp:D '*:S'

MyApp ≥ Debug；其他静默；星号需引号

按进程筛选
adb logcat --pid=12345

12345 换成 pidof 返回的 PID；重启应用后需更新

导出当前日志
adb logcat -d -v threadtime > logcat.txt

-d 导出后退出；文件保存在本机

查看崩溃缓冲区
adb logcat -b crash -d

-b all 选择所有可访问缓冲区

清空日志缓冲区
adb logcat -c

清除选中缓冲区；先导出需要保留的日志

系统诊断

07
导出诊断报告
adb bugreport ./bugreport.zip

输出在本机；报告可能含设备与应用信息

列出可诊断服务
adb shell dumpsys -l

指定服务可缩小输出范围

电池与充电状态
adb shell dumpsys battery
应用内存
adb shell dumpsys meminfo com.example.app

PSS、堆与其他内存分类

界面渲染统计
adb shell dumpsys gfxinfo com.example.app framestats

受渲染路径与系统版本影响

查询应用 PID
adb shell pidof com.example.app

应用需正在运行；子进程可能使用其他进程名

CPU 与进程负载
adb shell top -b -n 1

单次输出；可用选项以设备 top --help 为准

屏幕与输入

07
截图到本机
adb exec-out screencap -p > screen.png

PNG 二进制输出；此重定向示例适用于 Bash / Zsh

录屏并下载
adb shell screenrecord --time-limit 15 /sdcard/demo.mp4
adb pull /sdcard/demo.mp4 .

15 秒；受保护画面可能无法录制

发送按键
adb shell input keyevent KEYCODE_HOME

常用：KEYCODE_BACK / KEYCODE_ENTER / KEYCODE_POWER

点击屏幕
adb shell input tap 300 500

坐标单位为像素；按当前分辨率调整

滑动手势
adb shell input swipe 300 1000 300 300 400

起点 x/y → 终点 x/y；最后一项为毫秒

输入文本
adb shell input text hello%sworld

%s 表示空格；适合 ASCII，不保证任意 Unicode

查询分辨率与密度
adb shell wm size
adb shell wm density

查看物理值与 override；size reset / density reset 清除覆盖

端口与网络

06
本机端口 → 设备
adb forward tcp:8081 tcp:8080

访问本机 8081 → 设备 8080；本机指 ADB server 所在主机

设备端口 → 本机
adb reverse tcp:8080 tcp:8000

设备访问 localhost:8080 → ADB server 主机的 8000

列出端口映射
adb forward --list
adb reverse --list
移除正向映射
adb forward --remove tcp:8081

参数是本机监听端口

移除反向映射
adb reverse --remove tcp:8080

参数是设备监听端口

查看地址与路由
adb shell ip addr show wlan0
adb shell ip route

接口名按设备调整；可见信息受系统权限限制

权限与设置

07
系统版本与 API level
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk

getprop 不带键名可列出可见属性

读取系统设置
adb shell settings get system screen_off_timeout

毫秒；另有 secure / global 命名空间

修改熄屏超时
adb shell settings put system screen_off_timeout 600000

10 分钟；先记录原值，恢复时写回原值

授予运行时权限
adb shell pm grant com.example.app android.permission.CAMERA

应用须已声明该可变更权限；不适用于任意特殊权限

撤销运行时权限
adb shell pm revoke com.example.app android.permission.CAMERA

系统固定等权限不能任意撤销

对用户停用应用
adb shell pm disable-user --user 0 com.example.app

用户 0；执行前确认目标，部分系统包禁止停用

恢复启用应用
adb shell pm enable --user 0 com.example.app

与 disable-user 使用同一用户和包名

服务与重启

08
启动本机 ADB server
adb start-server

通常会自动启动；默认本机端口 5037

停止本机 ADB server
adb kill-server

会中断使用该 server 的设备连接与调试会话

重连异常设备
adb reconnect offline

重置 offline / unauthorized 连接；仍需手机授权

等待设备连接
adb wait-for-device

仅表示 adbd 已连接，不代表 Android 开机完成

检查开机完成状态
adb shell getprop sys.boot_completed

通常为 1 时已完成开机；此命令不主动等待

重启设备
adb reboot

立即重启；当前设备会话会断开

重启到 Recovery
adb reboot recovery

恢复模式；支持情况因设备而异

重启到 Bootloader
adb reboot bootloader

之后常需使用 fastboot；fastboot 是另一套工具

开发调试

06
访问可调试应用目录
adb shell run-as com.example.app ls files

仅限允许 run-as 的 debuggable 应用，不是任意应用 root 访问

列出 Java 调试进程
adb jdwp

输出提供 JDWP transport 的进程 PID

转发 JDWP 调试端口
adb forward tcp:8700 jdwp:12345

12345 换成 adb jdwp 返回的 PID；本机调试器连接 8700

以 root 重启 adbd
adb root

仅支持允许 root 的开发镜像；普通零售 user 构建通常拒绝

恢复非 root adbd
adb unroot

会重启 adbd 并短暂断开连接

查询双方支持的特性
adb features
adb host-features

features 为主机与设备共同支持；host-features 只查主机

示例采用 Bash/Zsh；IP、端口、序列号、包名和路径按实际替换。命令支持取决于 Platform-Tools、Android 版本与设备权限。Platform-ToolsADB 官方说明命令手册

Wireless debugging

06
Pair wirelessly
adb pair 192.168.1.20:37001

Android 11+ phones; use the pairing-dialog port and enter its code

Connect wirelessly
adb connect 192.168.1.20:38001

Use the connection port on the Wireless debugging screen, not the pairing port

Discover wireless services
adb mdns check
adb mdns services

Usually the same network; discovery depends on mDNS

Disconnect a wireless device
adb disconnect 192.168.1.20:38001

adb tcpip 5555
adb connect 192.168.1.20:5555

Usually authorize over USB first; trusted network only, not TLS pairing

Return to USB listening
adb usb

Restarts target adbd listening; use after legacy TCP debugging

07
Upload a file

Host → device; directories are also supported

Upload newer files

adb shell df -h /sdcard

adb shell rm /sdcard/Download/adb-demo/note.txt

App installation

07
Install an APK
adb install ./app.apk

-t allows test APKs; -g grants runtime permissions

Replace an installed app
adb install -r ./app.apk

Preserves data; signatures must match, downgrade rules still apply

Install split APKs
adb install-multiple base.apk split_config.arm64_v8a.apk

One app; include every required split matching the device

Uninstall an app
adb uninstall com.example.app

Deletes data by default; -k keeps data and cache

Clear app data
adb shell pm clear com.example.app

Keeps the APK; removes app data and sign-in state

List installed apps
adb shell pm list packages -3

-3 third-party; -s system; -f includes APK paths

Locate installed APKs
adb shell pm path com.example.app

Split installs return multiple paths; pull each one if needed

App execution

06
Open a device shell
adb shell

exit leaves the shell; the shell user is not root

Launch an Activity
adb shell am start -W -n com.example.app/.MainActivity

-W waits for launch results; use the actual component name

Open a URL
adb shell am start -a android.intent.action.VIEW -d https://example.com/

Handled by a matching app on the device

Force-stop an app
adb shell am force-stop com.example.app

Stops the package without uninstalling or clearing its data

Send an app broadcast
adb shell am broadcast -a com.example.app.PING -p com.example.app

Receiver export and broadcast permissions apply

Run instrumentation tests
adb shell am instrument -w com.example.app.test/androidx.test.runner.AndroidJUnitRunner

Install the test APK first; use its package and runner

Logcat

06
Stream logs
adb logcat -v threadtime

Ctrl+C stops; includes timestamps, PID, and TID

Filter tags and priorities
adb logcat MyApp:D '*:S'

MyApp at Debug or higher; silence others; quote the wildcard

Filter a process
adb logcat --pid=12345

Use the PID returned by pidof; refresh after app restart

Save current logs
adb logcat -d -v threadtime > logcat.txt

-d dumps and exits; the file is saved on the host

Read the crash buffer
adb logcat -b crash -d

-b all selects all accessible buffers

Clear log buffers
adb logcat -c

Clears selected buffers; export needed logs first

Ports and networking

06
Host port → device
adb forward tcp:8081 tcp:8080

Host 8081 → device 8080; host means the ADB server machine

Device port → host
adb reverse tcp:8080 tcp:8000

Device localhost:8080 → port 8000 on the ADB server host

List port mappings
adb forward --list
adb reverse --list
Remove a forward mapping
adb forward --remove tcp:8081

Use the host listening port

Remove a reverse mapping
adb reverse --remove tcp:8080

Use the device listening port

Inspect addresses and routes
adb shell ip addr show wlan0
adb shell ip route

Adjust the interface name; system permissions restrict visibility

Permissions and settings

07
OS version and API level
adb shell getprop ro.build.version.release
adb shell getprop ro.build.version.sdk

getprop without a key lists visible properties

Read a system setting
adb shell settings get system screen_off_timeout

Milliseconds; secure / global are other namespaces

Change screen timeout
adb shell settings put system screen_off_timeout 600000

10 minutes; record and restore the original value

Grant a runtime permission
adb shell pm grant com.example.app android.permission.CAMERA

The app must declare an eligible permission; not for arbitrary special access

Revoke a runtime permission
adb shell pm revoke com.example.app android.permission.CAMERA

System-fixed and other restricted permissions cannot be freely revoked

Disable an app for a user
adb shell pm disable-user --user 0 com.example.app

User 0; verify the package, some system apps cannot be disabled

Re-enable an app
adb shell pm enable --user 0 com.example.app

Use the same user and package as disable-user

Server and reboot

08
Start the host ADB server
adb start-server

Usually starts automatically; default host port 5037

Stop the host ADB server
adb kill-server

Interrupts device connections and debug sessions using this server

Reconnect unavailable devices
adb reconnect offline

Resets offline / unauthorized connections; authorization is still required

Wait for a device connection
adb wait-for-device

Waits for adbd, not for Android to finish booting

Check boot completion
adb shell getprop sys.boot_completed

Usually 1 after boot completes; this command does not wait

Reboot the device
adb reboot

Reboots immediately; current device sessions disconnect

Reboot to recovery
adb reboot recovery

Recovery mode; support varies by device

Reboot to bootloader
adb reboot bootloader

Usually use fastboot afterward; it is a separate tool

Development tools

06
Access a debuggable app directory
adb shell run-as com.example.app ls files

Requires an eligible debuggable app; not root access to arbitrary apps

List Java debug processes
adb jdwp

Lists PIDs exposing JDWP transport

Forward a JDWP debug port
adb forward tcp:8700 jdwp:12345

Use a PID from adb jdwp; attach the host debugger to 8700

Restart adbd as root
adb root

Requires a root-capable development image; retail user builds usually reject it

Return adbd to non-root mode
adb unroot

Restarts adbd and briefly disconnects

Inspect supported features
adb features
adb host-features

features is the common set; host-features checks only the host
