Sliding Window Attention 的 Packing 边界与样本隔离

Sequence packing 把多条短样本拼入同一个 token buffer，以提高有效 token 比例；Sliding Window Attention（SWA）把每层的注意力限制在局部窗口内。训练系统同时采用两者时，需要保留一项基本语义：每条样本的输出与梯度只能依赖本样本。SWA 描述局部位置关系，packing 则引入文档边界，两种约束作用在不同层面。

1. 问题设定

对于因果 SWA，窗口宽度 \(W\) 表示一个 token 在单层中可以读取自身及前 \(W-1\) 个位置。Sequence packing 则把若干独立样本首尾相接，并用一组连续存储承载它们。若 attention mask 只编码因果关系和窗口距离，算子看到的是一个长序列，其中没有样本归属这一维信息。

独立训练等价性要求 packed 计算图在样本边界处保持断开。单层窗口限制只约束一跳 attention edge；模型堆叠多层后，这些局部 edge 会组成更长的依赖路径。因此，边界两侧即使没有一次跨越整个窗口的 attention，信息仍可能逐层传播到另一条样本。

下面使用 6 个 token、2 层和 \(W=3\) 的最小例子追踪这条路径，再把结果对应到 FlashAttention 的 cu_seqlens 与 document mask。

Packing Boundaries and Sample Isolation in Sliding Window Attention

Sequence packing concatenates short samples into one token buffer to raise the fraction of useful tokens. Sliding Window Attention (SWA) restricts attention in each layer to a local neighborhood. A training system that combines them must preserve a basic semantic invariant: the outputs and gradients of one sample may depend only on that sample. SWA describes positional locality, whereas packing introduces document boundaries; the two constraints operate at different levels.

1. Problem setting

For causal SWA, a window width \(W\) lets each token read itself and the previous \(W-1\) positions in one layer. Sequence packing places several independent samples back to back in contiguous storage. When the attention mask encodes only causality and window distance, the operator sees one long sequence with no notion of sample ownership.

Equivalence with independent training requires the packed computation graph to remain disconnected at every sample boundary. A per-layer window constrains only one-hop attention edges. Once layers are stacked, those local edges compose into longer dependency paths, allowing information to cross a boundary without any single attention operation spanning the full distance.

The smallest example below uses six tokens, two layers, and \(W=3\) to trace such a path, then connects the result to FlashAttention's cu_seqlens and document masks.

2. 单层窗口的直接感受野

设序列为 abcdef，窗口 \(W=3\)，并采用因果 mask。一层 SWA 把输入 activation \(\mathrm{act}_0\) 变成 \(\mathrm{act}_1\)。位置 4 的 d 直接读取 \(\mathrm{act}_0\) 中的 \(\{b,c,d\}\)，这三个位置构成它在该层的直接感受野。

2. The direct receptive field of one layer

Consider abcdef with \(W=3\) and a causal mask. One SWA layer maps the input activation \(\mathrm{act}_0\) to \(\mathrm{act}_1\). Position 4, d, reads \(\{b,c,d\}\) from \(\mathrm{act}_0\); these three positions form its direct receptive field in that layer.

把同一约束写成 attention mask 矩阵时，行对应 \(Q\)，列对应 \(K\)。因果条件保留下三角区域，窗口条件再将距离超过 \(W-1\) 的位置移除，最终得到一条沿对角线展开、宽度为 \(W\) 的下三角带。

In matrix form, rows correspond to \(Q\) and columns to \(K\). Causality retains the lower triangle, and the window condition removes positions farther than \(W-1\). The resulting attention region is a lower-triangular band of width \(W\) along the diagonal.

3. 层间传播与有效感受野

第二层把 act₁ 变成 act₂。此时 d 仍只直接读取 act₁ 的 $\{b,c,d\}$，窗口宽度没有变化。不过，act₁ 中的 b 已在上一层读取 act₀ 的 $\{a,b\}$。沿着 \(a \rightarrow b \rightarrow d\) 这条两跳路径，a 的信息进入了 act₂ 的 d。

于是，act₂ 中 d 相对于 act₀ 的有效感受野扩展为 $\{a,b,c,d\}$。直接感受野描述一层内的 edge，有效感受野则描述多层计算图中可达的输入位置。

3. Cross-layer propagation and the effective receptive field

A second layer maps act₁ to act₂. Position d still reads only $\{b,c,d\}$ directly from act₁, so the per-layer window remains unchanged. However, b in act₁ already read $\{a,b\}$ from act₀. The two-hop path \(a \rightarrow b \rightarrow d\) therefore carries information from a into d at act₂.

The effective receptive field of d at act₂, measured against act₀, is therefore $\{a,b,c,d\}$. The direct receptive field names the edges in one layer; the effective receptive field names the input positions reachable through the stacked computation graph.

4. \(L\) 层 SWA 的感受野上界

每一层最多把依赖范围向前扩展 \(W-1\) 个位置。忽略序列起点截断后，堆叠 \(L\) 层得到的最大理论感受野为：

$$\text{ERF}(L, W) \;=\; L \cdot (W - 1) + 1 \quad \text{token}$$

其中 ERF 表示 effective receptive field。下表列出几个窗口与层数配置：

5. Packing 训练中的跨样本污染

把两条独立样本 ABC 与 BCD 拼成 ABCBCD，并分别只在末尾 token 上计算 loss，便得到与前文同样长度的 6-token 例子。现在使用 \(W=3\) 的因果 SWA 运行两层，并把第二条样本在 act₂ 中的 D 作为目标。样本边界位于位置 3 与位置 4 之间。

5. Packed training: where the contamination happens

Concatenate two independent samples, ABC and BCD, into ABCBCD, and compute loss only at the final token of each sample. This produces the same six-token length used above. Run two layers of causal SWA with \(W=3\), taking the D of the second sample at act₂ as the target. The sample boundary lies between positions 3 and 4.

这条跨边界路径可以逐层展开：

  • 位置 4 的 B 属于 sample 2，但它在 act₁ 中读取 act₀ 的位置 2、3、4，即 $\{B_{s1},C_{s1},B_{s2}\}$。跨样本依赖在第一层已经形成。
  • 位置 6 的 D 在 act₂ 中读取 act₁ 的位置 4、5、6，即 $\{B_{s1+s2 \, \text{mix}},C_{s2},D_{s2}\}$。第一层的混合 activation 因而继续流向目标。
  • Sample 1 的 $\{B,C\}$ 由此进入 D 的 logit 及其反向路径，所得梯度与单独训练 BCD 时不同。在两层、\(W=3\) 的配置中，位置 1 的 A 位于 5-token ERF 之外；再增加一层后，依赖范围会覆盖它。

这条路径同时改变前向统计。第二条样本边界附近的 attention 分布和 hidden state 会包含 sample 1 的 token，模型因而接触到训练数据中原本不存在的跨文档邻接关系，例如 \(C_{s1} \rightarrow B_{s2}\)。

窗口缩小会降低每层扩展的步长，但不会编码样本边界。只要层数使 \(L(W-1)+1\) 覆盖边界，跨样本路径便会出现；更大的 \(W\) 或更深的 \(L\) 会扩大可能受影响的范围。

The cross-boundary path unfolds one layer at a time:

  • Position 4, B in sample 2, reads positions 2, 3, and 4 of act₀ when producing act₁: $\{B_{s1},C_{s1},B_{s2}\}$. The first cross-sample dependency is created in this layer.
  • Position 6, D, then reads positions 4, 5, and 6 of act₁: $\{B_{s1+s2 \, \text{mixed}},C_{s2},D_{s2}\}$. The mixed activation from the first layer now reaches the target.
  • Sample 1's $\{B,C\}$ consequently enters the logit and backward path of D, producing a different gradient from independent training on BCD. With two layers and \(W=3\), position 1, A, remains outside the five-token ERF; one additional layer brings it into range.

The forward statistics change as well. Attention distributions and hidden states near the second sample's boundary include tokens from sample 1, exposing the model to cross-document adjacencies that do not exist in the original data, such as \(C_{s1} \rightarrow B_{s2}\).

A smaller window reduces the expansion per layer but does not encode sample boundaries. A cross-sample path appears whenever \(L(W-1)+1\) reaches across a boundary; increasing \(W\) or \(L\) expands the range that may be affected.

6. 文档边界编码：document mask 与 cu_seqlens

Document mask 是按样本归属限制 attention edge 的 mask。它把每条样本对应的因果 attention 子矩阵放在对角块内，并把跨块分数设为 \(-\infty\)。于是 softmax 后的跨样本权重为零，packed attention 在边界处保持断开。

      A B C B C D
   A [• . . . . .]    sample 1 内部:三角形
   B [• • . . . .]
   C [• • • . . .]
   B [. . . × . .]    跨样本的 attention = 0
   C [. . . • • .]    sample 2 内部:三角形
   D [. . . • • •]
        ↑
   sample 1 / 2 边界,× 全部 mask 掉

FlashAttention 的 flash_attn_varlen_func 用 cu_seqlens（cumulative sequence lengths）表示各条序列在 packed buffer 中的起止位置：

from flash_attn import flash_attn_varlen_func

# 两条样本:ABC (长度 3) 和 BCD (长度 3),拼成 6-token
cu_seqlens = torch.tensor([0, 3, 6], dtype=torch.int32)

out = flash_attn_varlen_func(
    q, k, v,
    cu_seqlens_q=cu_seqlens,
    cu_seqlens_k=cu_seqlens,
    max_seqlen_q=3, max_seqlen_k=3,
    causal=True,
    window_size=(2, 0),    # 因果 + SWA,W=3 → left=W-1=2
)

cu_seqlens 把 packed buffer 描述成多条独立序列。对于 attention 算子，这与逐条计算后再拼接输出等价。整张模型计算图还包含位置编码、dropout 随机数及其它可能跨 token 或 batch element 聚合的算子，它们也需要满足同一隔离条件。

Megatron-LM 的 reset_attention_mask 在 EOD 后切断对前一 document 的 attention，reset_position_ids 则独立控制位置编号。普通二维 padding mask 通常只描述有效长度，无法表达一个 packed buffer 内部的多个 document 边界；训练框架必须提供 block-diagonal mask 或等价的 varlen metadata。

6. Encoding document boundaries with masks and cu_seqlens

A document mask restricts attention edges by sample ownership. It places the causal attention matrix of each sample in a diagonal block and sets cross-block scores to \(-\infty\). Their softmax weights become zero, leaving the packed attention graph disconnected at every boundary.

      A B C B C D
   A [• . . . . .]    inside sample 1: a triangle
   B [• • . . . .]
   C [• • • . . .]
   B [. . . × . .]    cross-sample attention = 0
   C [. . . • • .]    inside sample 2: a triangle
   D [. . . • • •]
        ↑
   sample 1 / 2 boundary, × is masked out

FlashAttention's flash_attn_varlen_func uses cu_seqlens, or cumulative sequence lengths, to encode where each sequence begins and ends in the packed buffer:

from flash_attn import flash_attn_varlen_func

# Two samples: ABC (len 3) and BCD (len 3), packed into a 6-token batch
cu_seqlens = torch.tensor([0, 3, 6], dtype=torch.int32)

out = flash_attn_varlen_func(
    q, k, v,
    cu_seqlens_q=cu_seqlens,
    cu_seqlens_k=cu_seqlens,
    max_seqlen_q=3, max_seqlen_k=3,
    causal=True,
    window_size=(2, 0),    # causal + SWA, W=3 → left=W-1=2
)

cu_seqlens describes the packed buffer as several independent sequences. For the attention operator, this is equivalent to evaluating each sequence separately and concatenating the outputs. The complete model graph also contains positional encoding, dropout RNG, and possibly other operators that aggregate across tokens or batch elements; those operations must preserve the same isolation.

Megatron-LM's reset_attention_mask cuts attention across EOD boundaries, while reset_position_ids controls position numbering independently. A conventional 2D padding mask usually describes valid lengths and cannot represent several document boundaries inside one packed buffer. The training stack therefore needs a block-diagonal mask or equivalent variable-length metadata.

7. 等价性验证

配置Attention 隔离说明
拼接 + 普通因果 mask❌第一层即可读取前一条样本
拼接 + 因果 + SWA（单层）❌窗口覆盖边界时立即产生跨样本 edge
拼接 + 因果 + SWA（多层）❌有效感受野按 \(L(W-1)+1\) 扩展
拼接 + cu_seqlens（document mask）✅attention 子图按样本形成对角块
拼接 + cu_seqlens + SWA✅每条样本内部继续采用局部窗口

验证工作应覆盖 attention metadata、位置语义和 loss 语义：

  • 训练框架：
    • Megatron-LM 使用 --reset-attention-mask，并通过 <eod> 标记数据边界；--reset-position-ids 是否启用取决于位置编码和目标等价性。
    • HF Transformers 需要确认具体 model/backend 是否接收 block-diagonal mask 或 varlen metadata；普通 padding mask 无法表达 packed document 边界。
    • 直接调用 FlashAttention 时，varlen packed 输入对应 flash_attn_varlen_func。
  • Mask 结构：打印 attention mask 的形状与非零分布。单一大三角形表示所有 token 属于同一序列；按样本隔离的 mask 应在边界处形成清晰断点。
  • 位置编码：绝对位置编码通常需要在边界重置，才能复现逐样本执行。标准 RoPE 的 attention score 对单个 segment 内的统一位置平移具有不变性，具体配置仍应结合模型实现核对。
  • Loss mask：loss mask 决定哪些位置贡献训练目标，attention mask 决定 hidden state 可以读取哪些位置。两者承担不同语义，需要分别验证。

至此可以看出，packing 的正确性条件来自样本边界，而窗口只规定样本内部的局部连接。训练系统需要用 cu_seqlens 或 segment-aware attention_mask 编码前者，再由 SWA 决定每个对角块内部的可见范围。

7. Equivalence checks

ConfigurationAttention isolationNotes
Concat + plain causal mask❌The first layer can read the preceding sample
Concat + causal + SWA (one layer)❌A window that reaches the boundary creates a cross-sample edge immediately
Concat + causal + SWA (multiple layers)❌The effective receptive field expands as \(L(W-1)+1\)
Concat + cu_seqlens (document mask)✅Each sample forms a diagonal attention subgraph
Concat + cu_seqlens + SWA✅The local window remains active within each sample

Validation should cover attention metadata, position semantics, and loss semantics:

  • Training framework:
    • Megatron-LM uses --reset-attention-mask together with <eod> data boundaries. Whether --reset-position-ids is also required depends on positional encoding and the target notion of equivalence.
    • For HF Transformers, verify that the model and backend accept a block-diagonal mask or variable-length metadata. A regular padding mask cannot represent packed document boundaries.
    • Direct FlashAttention calls use flash_attn_varlen_func for variable-length packed input.
  • Mask structure: inspect the shape and nonzero distribution of the attention mask. One large triangle treats all tokens as a single sequence; an isolated mask has visible breaks at sample boundaries.
  • Position encoding: absolute position embeddings usually need a boundary reset to reproduce per-sample execution. Standard RoPE attention scores are invariant to a uniform position shift within one segment, so the required setting depends on the model implementation.
  • Loss mask: a loss mask selects positions that contribute training targets, while an attention mask selects positions visible to hidden states. Validate these two semantics independently.

Packing correctness follows from document boundaries, while SWA defines local connectivity inside each document. A training system first encodes boundaries with cu_seqlens or a segment-aware attention_mask, then applies the sliding window within each diagonal block.
