Chrome 快捷键速查

Chrome 常用快捷键，按标签页、页面浏览、文本编辑、浏览器功能和地址栏分类，提供 Windows/Linux 与 macOS 对照。

Chrome Keyboard Shortcuts

Chrome keyboard shortcuts for tabs, navigation, text editing, browser features, and the address bar, with Windows/Linux and macOS side by side.

按键说明：Cmd = ⌘ Command，Option = ⌥；Ctrl 在 Mac 上指 Control。 + 表示同时按下，斜线表示左右／首尾两个对应选项。1–8 表示任选一个数字键。“未列出”表示本表未收录该平台的对应组合。

滚动快捷键用于页面未聚焦输入框时；文本编辑快捷键用于输入框或可编辑区域。Linux 窗口管理快捷键可能由桌面环境接管，标注 Windows 的项仅适用于 Windows。

Key notation: Cmd = ⌘ Command; Option = ⌥. On Mac, Ctrl means Control. A + joins keys pressed together; a slash separates paired directions or endpoints. 1–8 means any one of those number keys. “Not listed” means this sheet does not list a matching combination.

Scrolling shortcuts apply when focus is outside a text field; editing shortcuts apply inside text fields or editable content. Linux desktop environments may intercept window shortcuts. Entries marked Windows apply only to Windows.
