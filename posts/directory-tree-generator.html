Directory Tree Generator

Turn a directory hierarchy into copyable text. Add nodes with your keyboard or mouse and generate a tree for READMEs, documentation, and terminals.

ASCII 使用竖线、连字符和反引号；Unicode 使用连续的制表符号。缩进均为空格，目录名保持原样，包括中文。ASCII uses pipes, hyphens, and backticks; Unicode uses box-drawing characters. Indentation uses spaces. Names, including non-ASCII names, stay unchanged.

选中节点后可直接输入新名称。↑ ↓ 按显示顺序跳转到上一行或下一行，跨层级连续移动。Tab / Enter 在命名时同样可用，Shift + Tab 按网页的正常顺序移动焦点。

          
Delete 删除选中节点及其子树，根节点保留。树导航时 Ctrl / ⌘ + Z 撤销，Ctrl / ⌘ + Shift + Z 重做；编辑文字时保留输入框的原生撤销。载入示例、重新开始和删除均可撤销。

          
节点可以表示目录或文件，名称按原样输出。编辑和生成均在浏览器内完成；可用时自动保存到本浏览器，下次打开即可继续。

        

        

          
Type on a selected node to replace its name. ↑ ↓ move to the previous or next row in display order, across nesting levels. Tab / Enter also work while naming. Shift + Tab follows normal page focus order.

          
Delete removes a node and its subtree; the root is retained. In tree navigation, Ctrl / ⌘ + Z undoes and Ctrl / ⌘ + Shift + Z redoes. Text inputs keep native text undo. Loading the example, starting over, and deleting can all be undone.

          
Nodes can represent directories or files; names are output as written. Editing and generation run in your browser. When available, browser storage saves your tree for your next visit.
