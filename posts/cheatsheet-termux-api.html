Termux:API 命令速查

Termux:API 将 Android 的电量、剪贴板、通知、相机、音频、定位与文档访问能力接入 Shell。本文收录 termux-api 0.60.0 提供的全部 57 个命令入口，其中包括一个已废弃入口，按用途整理示例、常用参数和执行条件，命令名可直接打开对应源码。

1. 安装与检查

插件与命令包

主线 Termux 需要两个部分：手机上安装 Termux:API Android 插件，终端里安装 termux-api 命令包。Termux 与插件需要兼容的签名，应使用同一安装来源；只执行 pkg install 不会安装 Android 插件。参见官方安装说明。

pkg update
pkg install termux-api jq

# Inspect the installed CLI package and its commands.
dpkg-query -W termux-api
dpkg -L termux-api | sed -n '\|/bin/termux-|p'

termux-battery-status
termux-toast -s "Termux:API ready"

命令脚本把请求交给 Termux:API，由插件调用 Android 服务并返回结果。许多查询返回 JSON，剪贴板和文档读取则可能返回纯文本或原始字节；先看实际输出，再决定是否接 jq。命令包版本与 Android 插件版本是两套版本号。

权限与版本

Google Play 分支已把部分 API 能力内建到主应用，支持范围与主线不同。本表以主线命令包的 v0.60.0 源码为基准；实际可用命令取决于已安装的命令包、Android 插件和设备，以 dpkg 输出及本地帮助为准。

联系人、短信、电话、相机、录音和定位分别受 Android 权限控制。“通知访问”和“修改系统设置”还可能需要在系统设置里单独授权。Shell 调用仍使用应用的权限边界；需要选择文件或确认权限时，应能操作手机上的系统界面。

3. 组合用法

电量通知

battery=$(termux-battery-status) || exit 1
percent=$(printf '%s' "$battery" | jq -er '.percentage | select(type == "number")') || exit 1
termux-notification --id 100 --title "电量" --content "${percent}%"

先检查返回值和 JSON 字段再拼接通知，避免把授权错误当成电量。

SAF 文件读写

DIR_URI=$(termux-saf-managedir) || exit 1
case "$DIR_URI" in content://*) ;; *) exit 1 ;; esac
FILE_URI=$(termux-saf-create -t text/plain "$DIR_URI" note.txt) || exit 1
case "$FILE_URI" in content://*) ;; *) exit 1 ;; esac
printf '%s\n' "hello from Termux" | termux-saf-write "$FILE_URI"
termux-saf-stat "$FILE_URI"
termux-saf-read "$FILE_URI"

目录授权返回 URI 后，再创建文件并写入。content:// URI 交给 SAF 命令，不能直接交给 cat、cp 或普通文件路径接口。

周期任务

mkdir -p "$HOME/bin"
cat > "$HOME/bin/check-battery.sh" <<'SH'
#!/data/data/com.termux/files/usr/bin/bash
set -euo pipefail
termux-battery-status | jq -c . >> "$HOME/battery-history.jsonl"
SH
chmod +x "$HOME/bin/check-battery.sh"
termux-job-scheduler --script "$HOME/bin/check-battery.sh" --job-id 7 --period-ms 900000
termux-job-scheduler --pending
# To remove this job later:
# termux-job-scheduler --cancel --job-id 7

Android 7+ 的周期下限为 15 分钟；Doze、网络、电量和后台政策会影响实际执行时间。--persisted true 可请求重启后保留任务，仍受系统条件约束。

4. 常见问题

现象检查方向
command not found检查 pkg install termux-api 和 dpkg -L termux-api；只装 APK 不会提供 Shell 命令。
命令一直等待或报权限错误检查插件安装、签名、手机上的授权弹窗及对应权限。启动保活服务不会自动授予权限。
后台会话读不到剪贴板检查 Android 前台访问限制，先在手机上测试；通过 SSH 调用也不会绕过系统权限。
普通文件工具打不开 SAF URI使用 termux-saf-read/write；content:// URI 不是文件系统路径。
周期任务没有准点执行JobScheduler 受约束条件和 Doze 影响，不是精确到时刻的 cron。
传感器或定位输出不结束sensor 用 -n 限定次数、-c 清理；单次定位用 -r once/last。updates 的行为还取决于插件版本。

Termux:API command cheatsheet

Termux:API exposes Android capabilities to shell commands: battery status, clipboard access, notifications, camera and audio, location, and authorized document storage. This sheet covers all 57 command entry points shipped in termux-api 0.60.0, including one retired entry, with examples and links to the corresponding scripts.

1. Setup

App and package

For the main Termux distribution, install the Termux:API Android plugin alongside Termux, then install the termux-api CLI package inside the terminal. Termux and its plugin must have compatible signatures, so use the same installation source. Installing the package alone does not install the Android app. Official installation notes.

pkg update
pkg install termux-api jq

# Inspect the installed CLI package and its commands.
dpkg-query -W termux-api
dpkg -L termux-api | sed -n '\|/bin/termux-|p'

termux-battery-status
termux-toast -s "Termux:API ready"

The scripts send requests to Termux:API, which invokes Android services and returns results. Many commands produce JSON, while clipboard and document reads can produce plain text or raw bytes. Inspect the output before piping it into jq. Package and Android app versions are separate.

Permissions and variants

The Google Play branch integrates some API functionality into its main app and has a different support list. This reference uses the main CLI package’s v0.60.0 source. Available commands depend on the installed package, Android app, and device; check the local command list and help.

Contacts, SMS, calls, camera, microphone, and location require their corresponding Android access. Notification listening and modifying system settings can require separate settings-page grants. A shell command retains the app’s permission boundaries; keep the phone UI available when a command opens a picker or permission prompt.

3. Recipes

Battery notification

battery=$(termux-battery-status) || exit 1
percent=$(printf '%s' "$battery" | jq -er '.percentage | select(type == "number")') || exit 1
termux-notification --id 100 --title "电量" --content "${percent}%"

Check the result and JSON field before building a notification, so a permission error is not treated as a battery value.

SAF file workflow

DIR_URI=$(termux-saf-managedir) || exit 1
case "$DIR_URI" in content://*) ;; *) exit 1 ;; esac
FILE_URI=$(termux-saf-create -t text/plain "$DIR_URI" note.txt) || exit 1
case "$FILE_URI" in content://*) ;; *) exit 1 ;; esac
printf '%s\n' "hello from Termux" | termux-saf-write "$FILE_URI"
termux-saf-stat "$FILE_URI"
termux-saf-read "$FILE_URI"

Authorize a tree, create a document, then write it. Pass content:// URIs to SAF commands rather than cat, cp, or ordinary filesystem APIs.

Periodic job

mkdir -p "$HOME/bin"
cat > "$HOME/bin/check-battery.sh" <<'SH'
#!/data/data/com.termux/files/usr/bin/bash
set -euo pipefail
termux-battery-status | jq -c . >> "$HOME/battery-history.jsonl"
SH
chmod +x "$HOME/bin/check-battery.sh"
termux-job-scheduler --script "$HOME/bin/check-battery.sh" --job-id 7 --period-ms 900000
termux-job-scheduler --pending
# To remove this job later:
# termux-job-scheduler --cancel --job-id 7

Android 7+ imposes a 15-minute minimum period. Doze, network, battery, and background rules affect execution time. --persisted true requests survival across reboot, subject to system conditions.

4. Troubleshooting

SymptomCheck
Command not foundCheck pkg install termux-api and dpkg -L termux-api. The APK alone does not provide shell scripts.
Command hangs or returns a permission errorCheck plugin installation/signature, visible permission dialogs, and the relevant Android permission. Service keep-alive does not grant access.
No clipboard text from a background sessionCheck Android foreground-access restrictions and test on the phone. SSH access does not bypass Android permissions.
SAF URI fails with normal file toolsUse termux-saf-read/write; a content:// URI is not a filesystem pathname.
Scheduled job runs lateJobScheduler is approximate and subject to constraints and Doze; it is not a precise cron clock.
Sensor/location output never finishesUse sensor -n for a sample limit, sensor -c for cleanup, and location -r once/last for single requests. updates behavior depends on the plugin version.

Related commands such as termux-info, termux-setup-storage, termux-open, and termux-wake-lock belong to other Termux tools and are not counted in these 57 entries. The libexec termux-api helper is an implementation detail, not an additional everyday user command.
